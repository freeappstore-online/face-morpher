# Face Morpher

Real-time funny face morphing effects using your camera — big eyes, wobble, alien, rainbow and more.

**Live:** https://face-morpher.freeappstore.online

A free app on [FreeAppStore](https://freeappstore.online). App id: `face-morpher`.

## Develop

```bash
pnpm install
pnpm dev
pnpm build
pnpm run typecheck
```

Before publishing, run `fas check` (`npm i -g @freeappstore/cli`). Pushing to `main` deploys the app.
